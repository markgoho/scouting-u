You've done a four-week activity cycle once already, for Second Class. This requirement asks for another one — a second full cycle, run and logged again — followed by an honest look at what it taught you.

## What You'll Complete

- 8a. **[Be physically active 4 weeks](/scouts-bsa/ranks/first-class/guide/req8a/)**: Complete another four-week cycle of daily activity, starting only after Second Class requirement 7a is done.
- 8b. **[Set a fitness goal](/scouts-bsa/ranks/first-class/guide/req8b/)**: Share what worked and what didn't from 8a, and set a goal for staying active going forward.

These two go in order — you need a finished four-week log before you have anything real to reflect on in 8b.
